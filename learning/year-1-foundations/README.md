## 🎯 Sau khi xong Year 1, bạn có thể

- Hiểu sâu CS fundamentals (Big-O, data structures, complexity)
- Đọc và viết Python hiện đại (async, typing, polars)
- Vận hành Linux + Docker + Kubernetes basics
- Thiết kế relational DB schema + hiểu MVCC/WAL
- So sánh NoSQL DB families + chọn đúng
- Hiểu distributed systems theory (CAP, consensus, CRDT)
- Apply system design patterns (CB, bulkhead, rate limit)
- Implement security basics (OAuth, JWT, TLS, secrets)
- Math foundations cho AI (probability, linear algebra)
