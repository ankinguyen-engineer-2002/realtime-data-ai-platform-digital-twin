# Notes — ghi nhanh khi học

> Ghi mọi thứ confused, lightbulb moment, câu hỏi nảy ra. Không cần đẹp.

---

## Format gợi ý

```markdown
## YYYY-MM-DD — KU XX/YY

**Lightbulb:**
- ...

**Confused:**
- ...

**Câu hỏi muốn hỏi:**
- ...

**Liên kết với thực tế dự án:**
- ...
```

---

## Khi nào dùng file này

- Đọc xong 1 KU → ghi 3 dòng ngay
- Đến cuối tuần → tổng hợp vào `lab-journal/YYYY-Www.md`
- Confused kéo dài 2 KU → tạo issue trong GitHub repo
